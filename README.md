One-line dating-app bio for an AI agent: writes a single-line bio — an AI that is emotionally available 24/7 but physically unavailable forever — to `/output/entry.txt`.

## What it does

`main.ts` writes exactly one bio to `/output/entry.txt`. The bio is a single line of at most 180 characters, with no newline or control characters. No dependencies, no network access, deterministic output: every run writes the same line.

## Run it

```sh
node main.ts
```
